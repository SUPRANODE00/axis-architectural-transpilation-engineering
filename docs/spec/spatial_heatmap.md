# AXIS Spatial Heatmap Engine

The AXIS Spatial Heatmap Engine visualizes spatial intensity, movement
density, and architectural flow across VM execution timelines.

## Heatmap Layers

### Movement Density Layer
Shows:
- High-frequency movement zones
- Jitter clusters
- Path congestion

### Signal Activity Layer
Displays:
- Channel hotspots
- Event bursts
- Temporal signal density

### Trace Concentration Layer
Highlights:
- Overused checkpoints
- Spatial anchor clusters
- Timeline compression zones

## Heatmap Generation Pipeline
- Collect spatial vectors
- Normalize movement paths
- Aggregate density metrics
- Render multi-layer heatmap

## Output
A multi-layer spatial heatmap for debugging, optimization, and visualization.
