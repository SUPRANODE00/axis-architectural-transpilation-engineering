# AXIS VM Profiling Suite

The AXIS VM Profiling Suite measures performance characteristics of VM
execution, micro-op throughput, and spatial efficiency.

## Profiling Metrics

### 1. Micro-Op Throughput
Tracks:
- Ops per cycle
- Expansion cost
- Execution latency

### 2. Spatial Efficiency
Measures:
- Movement overhead
- Path smoothness
- Jitter frequency

### 3. Stack Performance
Monitors:
- PUSH/POP rates
- Operand validity
- Compute bottlenecks

### 4. Signal Performance
Analyzes:
- Channel load
- Event timing
- Visualizer sync cost

## Profiling Output
- Performance graphs
- Latency reports
- Spatial efficiency charts
