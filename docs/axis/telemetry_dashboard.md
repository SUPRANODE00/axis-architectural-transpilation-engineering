# AXIS Sovereign Telemetry Dashboard

The Sovereign Telemetry Dashboard provides real-time metrics for:

## 1. System Load
- CPU_LOAD
- MEMORY_MB
- THREADS

## 2. Structural Complexity
- AST_NODES
- TOKENS

## 3. Aggregated Metrics
- Total volume
- Node distribution
- Percentage breakdown

## 4. Vector Registry
Displays:
- TRANSPILE_ID
- RAW_VOLUME
- NEG_VAL
